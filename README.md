髪や衣装だけを残して、それ以外のメッシュと、使っていない骨をまとめて消すUnityエディタ拡張です。

### 導入
VCC / ALCOM の Settings > Packages > Add Repository に次のURLを追加してください。

```
https://raw.githubusercontent.com/Torateihen/HairCostumeExtractor/main/index.json
```

### Ver1.4.10 の変更（1.4.7 から）
- 「アバターのまま残す」のチェックを足した。Descriptor・Animator・人型の骨を残したまま、要らない服・耳・しっぽと、その揺れ物と骨を消して、そのままアップロードできる
- 複製はアップロードすると新しいアバターになり、元のアバターは上書きされない
- VCC に移った時に消す物を、unitypackage が入れた物だけにした（取り出した物の置き場が残る）
