髪や衣装だけを残して、それ以外のメッシュと、使っていない骨をまとめて消すUnityエディタ拡張です。

### 導入
VCC / ALCOM の Settings > Packages > Add Repository に次のURLを追加してください。

```
https://raw.githubusercontent.com/Torateihen/HairCostumeExtractor/main/index.json
```

### Ver1.4.7 の変更（1.1.0 から）
- 取り出したものを、このシーンの別のアバターへ Modular Avatar でそのまま着せられるようにした
- 前髪の表示切り替えなどのメニューを、アイコンごと一緒に持っていけるようにした（Modular Avatar が入っているとき）
- 取り出したものが使うマテリアル・画像・メッシュを保存先に写し、別のプロジェクトへ持っていってもピンクにならないようにした
- 実行後に自己診断をして、前後を並べた画像を書き出すようにした
- 用途の推定に「角・耳」「しっぽ・翼」を足し、開いたときは「髪だけ」（髪と角・耳）にチェックが入るようにした
- ウィンドウのいちばん下に「ログを書き出す」「ログのフォルダを開く」を付けた
